# Request: agreement on test data and what may appear on screen

**To:** <data protection officer>

## Proposal

| Topic | Rule |
|---|---|
| Records the tool creates | Fictional, with names that start with Demo or Test (enforced by rule DS6). Deleted after each run. |
| Records that already exist in the test environment | May appear in lists. If they could contain personal data, they are blurred, or the list is filtered before recording. |
| Environment | Test, training or demo only. Production is rejected (rule DS3). |
| Credentials | Never on screen, and never in files that are shared. |
| Outputs (video, deck, guide) | Reviewed by the process owner before they are shared outside the team. |
| Retention | Recordings are regenerated, not archived. Old outputs are deleted when a new version is published. |

## Questions for you

1. Is the test environment's data copied from production? If so, is it masked?
2. May the outputs be shared with <external audiences, e.g. partners or teams in other countries>?
3. Is a privacy notice needed for the online voice service (see template 05)?
